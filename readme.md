Campus Ground is a unified platform that combines academic management with a campus-exclusive social network. It enables faculty to manage attendance, marks, assignments, notices, and events, while giving students a space to connect through clubs, achievements, challenges, and campus activities. The platform also features an anonymous protest system with expression and safety. Built using React, Tailwind CSS, Laravel, and MySQL, Campus Ground creates a smarter, more connected campus experience.
